# DSA Patterns

A personal notebook of reusable problem-solving patterns for coding interviews.

## How to use this
- Each file in `patterns/` covers one pattern.
- Each entry follows a **6-line template**: Pattern, Trigger, Key insight, Complexity, Trap.
- Revise **patterns**, not individual problems.
- Update the confidence column after each revision session.

## Revision Schedule

| When | Action |
|------|--------|
| Same day | Write the entry |
| 1 day later | Re-read Trigger + Trap lines |
| 3 days later | Re-solve 1 problem from scratch |
| 1 week later | Re-solve a *different* problem from the same pattern |
| 2 weeks later | Skim all pattern files, flag weak ones |
| 1 month later | Re-solve problems from weak patterns |
